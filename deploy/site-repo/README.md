# kubeaudit-ai.github.io

The public website for [KubeAudit AI](https://github.com/kubeaudit-ai/KubeAudit-Ai): https://kubeaudit-ai.github.io/

This repo has no source code of its own. Its workflow builds the web app from `web/` in
[kubeaudit-ai/KubeAudit-Ai](https://github.com/kubeaudit-ai/KubeAudit-Ai) and publishes it to GitHub Pages
every 30 minutes when there are new commits, or right away from **Actions → Deploy website → Run workflow**.

Settings needed once: **Settings → Pages → Source: GitHub Actions**.
